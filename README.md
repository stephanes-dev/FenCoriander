# FenCoriander

FenCoriander enables real-time spatial data integration and auto-scaling through a modular, distributed data processing engine API.

With FenCoriander, you get a lightweight tool that stays out of your way.

**What you get**

- FenCoriander enables real-time spatial data
- integration and auto-scaling through a
- modular, distributed data processing engine

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/FenCoriander.git`
2. `cd FenCoriander`
3. Install in editable mode: `pip install -e .`

## Configuration

FenCoriander is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
